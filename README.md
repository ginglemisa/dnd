# twD20｜5.5 版手機角卡

twD20 是 Reggie Tsai / 瑞基製作的手機角卡網站，協助新手快速建立 1～8 級角色、查閱規則摘要。

可用於 TRPG 體驗場、推廣活動、收費團；預設現場有主持人協助說明規則。

[正式網站](https://twd20.com) · [Legal & About](https://twd20.com/#legal-about-modal) · [GitHub](https://github.com/ginglemisa/dnd)

## 主要功能

- **創角與角色卡**：27 購點、屬性擲骰、快速創角與導覽，自動整理數值、技能、裝備、動作及法術。
- **跑團模式**：管理生命值、狀態、死亡豁免、專注、法術位與職業資源，操作武器攻擊、施法及擲骰。
- **保存與輸出**：本機自動儲存、JSON 匯入／匯出、分享網址、QR Code 與 PDF 角色卡。
- **冒險日誌**：記錄團錄與獎勵，支援書頁閱讀、全文搜尋及整本匯入／匯出。
- **外觀與離線使用**：暖紙／經典主題、亮色／暗色，以及不含 PDF 匯出的單檔離線版。

## 資料保存與分享

角色與冒險日誌保存在目前瀏覽器。清除網站資料、更換瀏覽器、App 或裝置可能遺失紀錄，請定期匯出 JSON 備份。

**角色與日誌須分別匯出**；角色 JSON 不包含日誌、頭像。

匯入角色 JSON 會取代目前角色，並重設相關本機紀錄與偏好；日誌及外觀設定會保留。

匯入日誌則會經確認後取代整本日誌，請先備份。

「分享角卡」可選擇資料直接包含在網址中的**永久網址**，或保存 **90 天**的 **TWD20 短網址**。

分享模式不自動儲存角色修改，停用分享與 JSON 匯入；保存只能透過匯出 JSON 或 PDF。

日誌不隨角色分享，清除角色紀錄也不會刪除日誌。

本站使用 Google Analytics 觀察整體使用情況，供更新參考，不用於商業行為；分享網址停用追蹤。
